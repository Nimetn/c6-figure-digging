# C6. Фигурное копание

Решение олимпиадной задачи по программированию: обработка протокола соревнований по фигурному копанию среди роботов.

## Условие задачи

Робототехническая Ассоциация Японии проводит чемпионат по фигурному копанию. Каждого робота-участника оценивают 6 роботов-судей по 65535-балльной системе. Итоговая оценка = среднее арифметическое оценок **без максимальной и минимальной**.

Программа должна определить трёх финалистов (1, 2 и 3 место).

### Формат входных данных (`robot.txt`)

- Первая строка — число `N` (3 ≤ N ≤ 255).
- Следующие `N` строк: имя робота (латиница + цифры, 1–20 символов) и 6 оценок (1–65535).

### Формат выходных данных (`Winners.txt`)

Три строки: имена роботов, занявших 1, 2 и 3 место.

## Возможности программы

- Проверка корректности входных данных.
- Удаление записей с оценками вне диапазона 1–65535.
- Удаление дубликатов по имени робота.
- Расчёт итоговой оценки (среднее без max и min).
- Сортировка по убыванию итоговой оценки (пузырьком).
- Вывод топ-3 в консоль и в файл.

## Основная идея реализации

Класс `BOT_Group` инкапсулирует:

- динамический массив структур `BOT_Points` (имя + оценки + среднее);
- методы валидации, фильтрации, сортировки и вывода.

Память под каждую запись и массив оценок выделяется динамически (`new[]`) и освобождается в деструкторе.

## Сборка и запуск (Code::Blocks, Windows)

### Требования

- Windows 10 / 11
- Code::Blocks с MinGW (g++)
- C++11 или новее

### Пошагово

1. **File → New → Project → Console application → C++**
2. Замени содержимое `main.cpp` кодом из `src/c6_figure_digging.cpp`.
3. Скопируй `tests/robot.txt` рядом с исполняемым файлом (обычно `bin/Debug/`).
4. **Build → Build and run** (или **F9**).
5. В консоли появится таблица участников, а в файле `Winners.txt` — топ-3.

### Кодировка

В коде используется `SetConsoleCP(1251)` / `SetConsoleOutputCP(1251)` — только для Windows. Файл должен быть сохранён в **Windows-1251**, иначе кириллица в консоли будет отображаться некорректно.
